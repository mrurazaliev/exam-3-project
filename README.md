# 🏥 Городской Медицинский Центр

## 📋 О проекте

Данный проект представляет собой современный адаптивный сайт медицинского центра, разработанный с использованием HTML5 и Tailwind CSS.

Сайт позволяет пользователям:

- Ознакомиться с услугами клиники
- Просмотреть информацию о врачах
- Узнать о действующих акциях
- Прочитать отзывы пациентов
- Изучить медицинское оборудование
- Ознакомиться со статьями блога
- Записаться на приём онлайн
- Найти контактную информацию

---

## 🚀 Используемые технологии

- HTML5
